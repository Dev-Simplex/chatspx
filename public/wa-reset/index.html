Etapa 4 — Se ainda ver diferente depois da limpeza

Chrome: F12 → Application → Storage → botão Clear site data (marcado tudo) → depois Ctrl+Shift+R.
Modo anônimo: Ctrl+Shift+N → acessa hmlchat.simplexsolucoes.com.br → loga. Se aparecer WhatsApp-fiel na janela anônima, é 100% cache da janela normal.
Outro browser: Firefox, Edge, Safari — se aparecer correto em outro browser, é cache isolado do Chrome normal.
