# Instruções para Criar Imagens das Conexões WhatsApp

Este documento contém instruções para criar as imagens necessárias para o artigo sobre Conexões WhatsApp na Central de Ajuda.

## Imagens Necessárias

Você precisará criar 3 imagens principais:

1. **conexoes-visao-geral.png** - Visão geral do gerenciador mostrando todas as conexões
2. **modal-adicionar-conexao.png** - Modal para adicionar uma nova conexão
3. **modal-qr-code.png** - Modal exibindo o QR Code para escanear

## Como Capturar as Imagens

### Opção 1: Captura de Tela Direta

1. Abra o sistema CHAT - SPX
2. Navegue até **Configurações** → **Conexões WhatsApp**
3. Aguarde o carregamento completo
4. Use a ferramenta de captura de tela do seu sistema operacional

### Opção 2: Ferramentas de Design

Você pode usar ferramentas como:
- **Figma** - Para criar mockups profissionais
- **GIMP** - Editor de imagens gratuito
- **Photoshop** - Editor profissional
- **Canva** - Ferramenta online fácil de usar

## Especificações das Imagens

### Dimensões Recomendadas
- **Largura**: 1200px a 1600px
- **Altura**: 800px a 1200px (dependendo do contexto)
- **Formato**: PNG (com transparência se necessário) ou JPG
- **Qualidade**: Alta resolução para clareza

### Estados a Capturar

#### 1. Visão Geral (conexoes-visao-geral.png)
- Tela completa do gerenciador
- Cabeçalho com logo WhatsApp e título
- Botão "Adicionar Nova Conexão" visível
- Grid de cards de conexões (pelo menos 2-3 cards)
- Indicadores de atualização automática

**Elementos a incluir:**
- Cabeçalho centralizado com:
  - Logo WhatsApp (círculo verde)
  - Título "Conexões WhatsApp"
  - Descrição
  - Botão grande "Adicionar Nova Conexão"
- Indicadores no topo:
  - Ponto verde pulsante (atualização automática)
  - Horário da última atualização
  - Botão "Atualizar"
- Grid de cards mostrando:
  - Pelo menos 2-3 cards de conexões
  - Cada card com:
    - Logo WhatsApp
    - Nome da conexão
    - Badge de status (Conectado/Escanear QR Code/etc)
    - Número de telefone (se conectado)
    - Nome da caixa de entrada
    - Data de criação
    - Botões de ação

#### 2. Modal Adicionar Conexão (modal-adicionar-conexao.png)
- Modal completo aberto
- Header com logo WhatsApp
- Campo de nome da conexão
- Botões de ação (Cancelar e Criar)

**Elementos a incluir:**
- Header do modal com:
  - Logo WhatsApp (círculo verde)
  - Título "Adicionar Conexão WhatsApp"
  - Descrição
- Formulário mostrando:
  - Campo "Nome da Conexão" com placeholder
  - Texto de ajuda abaixo do campo
  - Caixa de informação (info box) explicando o que acontece após criar
- Rodapé com:
  - Botão "Cancelar"
  - Botão "Criar Conexão" (verde)

#### 3. Modal QR Code (modal-qr-code.png)
- Modal completo com QR Code
- QR Code grande e visível
- Instruções passo a passo
- Status de aguardando conexão

**Elementos a incluir:**
- Header do modal com:
  - Ícone de QR Code (círculo verde)
  - Título "Escanear QR Code"
  - Nome da conexão
- Área central com:
  - QR Code grande (quadrado branco com código)
  - Bordas animadas nos cantos (opcional, pode ser estático na imagem)
- Instruções passo a passo:
  - 4 passos numerados explicando como escanear
  - Cada passo em um card/box
- Status no rodapé:
  - Indicador "Aguardando conexão..."
  - Timer mostrando tempo decorrido
- Botão "Cancelar" no rodapé

## Dicas de Captura

### Para a Primeira Imagem (Visão Geral)

1. Acesse a página de Conexões WhatsApp
2. Certifique-se de que há pelo menos 2-3 conexões criadas
3. Se não houver conexões, crie algumas para a captura
4. Capture a tela incluindo:
   - Todo o cabeçalho
   - Pelo menos 2-3 cards completos
   - Indicadores de atualização
5. Ajuste o zoom se necessário para mostrar mais conteúdo

**Dica**: Se você tiver muitas conexões, pode fazer scroll e capturar a parte superior com os cards principais.

### Para a Segunda Imagem (Modal Adicionar)

1. Clique no botão "Adicionar Nova Conexão"
2. Aguarde o modal abrir completamente
3. Capture o modal completo incluindo:
   - Header colorido
   - Campo de formulário
   - Caixa de informação
   - Botões do rodapé
4. Certifique-se de que o modal está centralizado e bem visível

**Dica**: Você pode preencher o campo com um nome de exemplo para melhor visualização.

### Para a Terceira Imagem (Modal QR Code)

1. Crie uma nova conexão ou clique em "QR Code" de uma existente
2. Aguarde o QR Code carregar completamente
3. Capture o modal completo incluindo:
   - Header
   - QR Code grande e claro
   - Instruções passo a passo
   - Status de aguardando
   - Botão cancelar
4. Certifique-se de que o QR Code está legível (mesmo que seja um exemplo)

**Dica**: O QR Code pode ser ofuscado ou substituído por um QR Code de exemplo para privacidade.

## Anotações e Destaques

Se necessário, você pode adicionar anotações nas imagens:

- **Setas**: Para apontar elementos importantes
- **Caixas de texto**: Para explicar funcionalidades
- **Destaques**: Para realçar áreas importantes
- **Números**: Para indicar ordem de ações
- **Legendas**: Para explicar o que está sendo mostrado

**Ferramentas recomendadas para anotações:**
- **Figma**: Para adicionar anotações profissionais
- **GIMP/Photoshop**: Para adicionar setas e textos
- **Canva**: Para adicionar elementos gráficos facilmente
- **Annotate** (Linux): Ferramenta simples para anotações rápidas

## Onde Salvar as Imagens

As imagens devem ser salvas em um local acessível. Quando você criar o artigo na Central de Ajuda:

1. Use o editor de artigos do sistema
2. Clique no botão de inserir imagem
3. Faça upload das imagens
4. Insira as imagens no artigo nos locais apropriados

## Considerações de Privacidade

⚠️ **IMPORTANTE**: Ao capturar imagens:

- **Remova dados pessoais**: Certifique-se de que não há informações sensíveis visíveis
  - Ofusque números de telefone reais
  - Use nomes genéricos (ex: "Conexão 1", "Atendimento Principal")
  - Remova ou ofusque QR Codes reais (use QR Codes de exemplo)
- **Use dados de teste**: Prefira usar contas e conexões de teste
- **Ofusque informações**: Se necessário, use ferramentas para ofuscar dados pessoais
- **Verifique permissões**: Certifique-se de que tem permissão para usar as imagens

## Dicas Adicionais

### Melhor Qualidade

- **Use resolução nativa**: Capture na resolução nativa da tela
- **Evite zoom excessivo**: Mantenha textos legíveis
- **Boa iluminação**: Se estiver fotografando uma tela, evite reflexos

### Organização

- **Nomeie os arquivos claramente**: Use nomes descritivos
- **Mantenha backup**: Salve as imagens em múltiplos locais
- **Versões**: Mantenha versões originais antes de editar

### Edição

- **Ajuste de brilho/contraste**: Se necessário, ajuste para melhor legibilidade
- **Recorte**: Remova áreas desnecessárias, mas mantenha contexto
- **Redimensionamento**: Mantenha proporção ao redimensionar
- **Ofuscação**: Use ferramentas para ofuscar QR Codes e números reais
