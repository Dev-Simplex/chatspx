# Guia: Como Adicionar o Artigo de Conexões WhatsApp na Central de Ajuda

Este guia explica passo a passo como adicionar o artigo sobre Conexões WhatsApp na Central de Ajuda do sistema.

## Pré-requisitos

- Acesso administrativo ao sistema CHAT - SPX
- Permissões para criar e editar artigos na Central de Ajuda
- As imagens das conexões já criadas (consulte `instrucoes-imagens-conexoes-whatsapp.md`)

## Passo 1: Acessar a Central de Ajuda

1. Faça login no sistema CHAT - SPX
2. Navegue até **Configurações** → **Central de Ajuda**
3. Selecione o portal onde deseja adicionar o artigo
4. Clique em **Artigos** no menu lateral

## Passo 2: Criar Novo Artigo

1. Clique no botão **Novo Artigo** ou **Criar Artigo**
2. Você será redirecionado para o editor de artigos

## Passo 3: Preencher Informações Básicas

### Título do Artigo
```
Conexões WhatsApp - Gerenciamento de Conexões - Nova Funcionalidade
```

### Categoria
- Selecione uma categoria apropriada (ex: "Configurações", "WhatsApp", "Integrações", "Funcionalidades")
- Ou crie uma nova categoria se necessário

### Autor
- Selecione o autor do artigo (geralmente você mesmo)

### Descrição (Meta Description)
```
Aprenda a gerenciar conexões WhatsApp no CHAT - SPX. Crie, conecte e gerencie múltiplas conexões WhatsApp para atendimento. Guia completo com instruções passo a passo e exemplos visuais.
```

## Passo 4: Adicionar Conteúdo

1. No editor de artigos, você verá um campo de título e um editor de texto rico
2. Copie o conteúdo do arquivo `artigo-conexoes-whatsapp.md`
3. Cole no editor de artigos

### Formatação no Editor

O editor suporta formatação rica. Use as seguintes formatações:

- **Títulos**: Use os botões de título (H1, H2, H3) para seções
- **Listas**: Use listas com marcadores (•) para itens
- **Negrito**: Destaque informações importantes
- **Imagens**: Insira as imagens nos locais indicados
- **Emojis**: Use emojis para tornar o conteúdo mais visual (se suportado)

## Passo 5: Adicionar Imagens

Para cada imagem mencionada no artigo:

1. Clique no local onde deseja inserir a imagem
2. Use o botão de inserir imagem do editor (geralmente um ícone de imagem)
3. Faça upload da imagem:
   - **conexoes-visao-geral.png** - Visão geral do gerenciador
   - **modal-adicionar-conexao.png** - Modal de adicionar conexão
   - **modal-qr-code.png** - Modal de QR Code

4. Adicione um texto alternativo descritivo para cada imagem
5. Ajuste o tamanho se necessário (recomendado: largura de 1200-1600px)

### Ordem das Imagens no Artigo

1. Primeira imagem: Após a seção "Exemplo Visual" - Visão geral
2. Segunda imagem: Após a primeira - Modal adicionar conexão
3. Terceira imagem: Após a segunda - Modal QR Code

## Passo 6: Revisar e Formatar

### Verificar Formatação

- [ ] Títulos estão formatados corretamente (H1, H2, H3)
- [ ] Listas estão formatadas como listas
- [ ] Emojis estão visíveis (se suportados)
- [ ] Imagens estão inseridas e visíveis
- [ ] Texto está legível e bem formatado
- [ ] Links estão funcionando (se houver)

### Ajustar Estilo

- Use negrito para destacar informações importantes
- Use listas para melhor legibilidade
- Mantenha parágrafos curtos e objetivos
- Use espaçamento adequado entre seções
- Destaque funcionalidades principais com emojis ou ícones

## Passo 7: Preview do Artigo

1. Clique no botão **Preview** ou **Visualizar**
2. Revise o artigo como ele aparecerá para os usuários
3. Verifique se:
   - Todas as imagens estão carregando
   - A formatação está correta
   - O texto está legível
   - Os links funcionam (se houver)
   - As imagens mostram claramente a funcionalidade

## Passo 8: Publicar o Artigo

### Opções de Status

1. **Rascunho (Draft)**: Salva sem publicar (para edições futuras)
2. **Publicado (Published)**: Torna o artigo visível para os usuários

### Publicar

1. Clique no botão **Publicar** no topo do editor
2. Confirme a publicação
3. O artigo estará disponível na Central de Ajuda

## Passo 9: Verificar Publicação

1. Acesse a Central de Ajuda como usuário final
2. Navegue até a categoria onde o artigo foi publicado
3. Verifique se:
   - O artigo aparece na lista
   - As imagens carregam corretamente
   - A formatação está preservada
   - O conteúdo está completo
   - As imagens mostram claramente a funcionalidade

## Solução de Problemas

### Imagens não carregam
- Verifique o tamanho do arquivo (máximo geralmente 4MB)
- Confirme o formato (PNG ou JPG)
- Tente fazer upload novamente
- Verifique se as imagens não contêm dados sensíveis

### Formatação perdida
- Use o editor de texto rico do sistema
- Evite copiar de editores que adicionam formatação oculta
- Use o botão "Limpar formatação" se disponível
- Verifique se emojis são suportados pelo editor

### Artigo não aparece
- Verifique o status (deve estar "Publicado")
- Confirme a categoria selecionada
- Verifique as permissões do portal
- Verifique se há filtros aplicados na visualização

### Imagens não mostram a funcionalidade claramente
- Certifique-se de que os cards de conexões estão visíveis
- Verifique se os modais estão completos
- Adicione anotações se necessário
- Use setas ou destaques para apontar elementos importantes
