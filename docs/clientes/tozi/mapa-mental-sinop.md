# Mapa mental de Sinop/MT — conhecimento local da IA imobiliária

> **Faixa** é padrão socioeconômico qualitativo (popular < médio < médio-alto < alto padrão), leitura de corretor — **nunca é preço**. Preço e estoque vêm **sempre** da busca no Vista (`buscar_imovel`), nunca deste mapa. As **regiões saem do centroide real** dos imóveis (mediana, robusta a erro de cadastro) — são orientação de bússola, não divisão oficial. Use este mapa só pra **orientar o cliente** ("é mais central", "vetor oeste", "condomínio fechado de alto padrão").
