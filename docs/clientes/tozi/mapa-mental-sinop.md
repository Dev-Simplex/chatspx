# Mapa mental de Sinop/MT — conhecimento para IA imobiliária

> **Faixa** = padrão socioeconômico qualitativo (popular < médio < médio-alto < alto padrão), leitura de corretor — **nunca é preço**. Preço/valor sempre vem da API Vista. Regiões (Central/Oeste/Norte/Leste/Sul/Rural) são orientação de bússola, não divisão oficial. Itens `[a confirmar]` têm baixa confiança de localização e carecem de geocoding.

## Eixos estruturantes (macro)
- **BR-163 (Rodovia Cuiabá–Santarém):** espinha norte-sul, corta a cidade inteira; organiza o Setor Industrial, as saídas e o vetor sul (Cidade Alta / Jardim Oriente / Alto da Glória).
- **Av. André Maggi (André Antônio Maggi):** corredor estruturante norte/oeste — bairros, áreas industriais e o cluster "Suíça".
- **Miolo central:** Av. Governador Júlio Campos, Av. das Figueiras (forte expansão), Av. das Itaúbas, Av. dos Tarumãs, Av. dos Jacarandás; Av. das Sibipirunas atravessa várias regiões.
- **Vetor nobre leste (sentido Aeroporto):** condomínios fechados de alto padrão (Portal da Mata, Aquarela da Mata, Carpe Diem/Hamoa, TUIM, San Martini).
