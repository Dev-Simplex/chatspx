## Fatos de plataforma que mudam a estratégia

- **WhatsApp = API oficial Meta Cloud** na Tozi c6 (inbox `[TOZI] FIXO` #91), **não WAHA**. → sem sinal de presença "digitando/gravando" pro negócio (mata debounce adaptativo por presença); status de entrega (`sent/delivered/read`) chega por webhook → dá pra auditar "não chegou" (18973) sem adivinhar. `AGENTS.md` ainda diz WAHA — desatualizado.
- **Mecânica do debounce** (`DebounceService`): cada entrada gera token novo e reagenda o job; só o último dispara (os antigos no-op via `stored_token == token`). Ou seja, **rajada de ENTRADA já é coalescida** — o buraco é a SAÍDA (P3), não a entrada. Aumentar `debounce_seconds` não resolve.
